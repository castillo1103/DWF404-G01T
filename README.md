<h1>🏛 Proyecto con Arquitectura Hexagonal</h1>

<h3>Este Proyecto se basa en la Arquitectura Hexagonal la cual es conocida por sus *Puertos y Adaptadores* para
excluir la lógica central de las funciones externas.</h3>
