<h1>🏛 Proyecto con Arquitectura Hexagonal</h1>

<h3>Este Proyecto se basa en la Arquitectura Hexagonal la cual es conocida por sus *Puertos y Adaptadores* para
excluir la lógica central de las funciones externas.</h3>

<h1>⚙️Dependencias añadidas</h1>

<h3>
  
-Lombok para menos código.
  
- H2 para base de datos simulada.
  
- Data JPA.
  
- Springboot Test.
  
- Springboot Web.
  
- Maven.
  
- Y las demás ya añadadidas por defecto al crear el proyecto en "https://start.spring.io/"</h3>


<h1>⚙️Las dependencias se pueden instalar ya sea desde terminal con la dirección de la carpeta con composer:</h1>

<h2>Composer install</h2>

<h2>O realizando el ciclo *Package* desde la configuración de Maven en IntelliJIDEA</h2>
