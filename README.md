# 🏗️  **Investigación Aplicada I**

Este repositorio contiene tres implementaciones prácticas de diferentes arquitecturas de software: Arquitectura Limpia, Arquitectura Hexagonal y Arquitectura Monolítica.
Cada implementación se encuentra en una rama independiente para facilitar su exploración y comparación.

📂 **Estructura del Repositorio**

main → Rama principal con este README.

arquitectura-limpia → Ejemplo de Clean Architecture con separación clara entre capas.

arquitectura-hexagonal → Ejemplo de Hexagonal Architecture (Ports & Adapters), enfocada en la flexibilidad de integraciones.

arquitectura-monolitica → Ejemplo de aplicación Monolítica, con todas las funcionalidades dentro de una única unidad.
