Definición del problema:

En los centros educativos, cuando se organizan salidas escolares, como excursiones o visitas guiadas, se necesita llevar un control claro de las reservas de buses y la cantidad de estudiantes que participarán. Muchas veces este proceso se hace en papel o por medios no organizados, lo que puede causar confusión, errores en la cantidad de personas o pérdida de información. Por eso, se necesita una forma más fácil y ordenada de registrar y consultar estas reservas para que todo esté más claro y bien gestionado todo esto lo he desarrollado por medio de arquitectura monolitica, es un programa simple pero funcional para mostrar el rendimiento, funcionamiento y organizacion de este tipo de arquitectura.

Para arrancarlo se debe iniciar el proyecto con la clase Ejemplo1Application y posteriormente entrar a:

--  http://localhost:8080/index.html

Para ver la base de datos debemos entrar a:

-- http://localhost:8080/h2-console

y entrar con las credenciales:

url=jdbc:h2:mem:guia-jpa;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE

y contraseña: sa
